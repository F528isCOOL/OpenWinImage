# OpenWinImage
Lightweight floppy image tool for Windows 95 to Windows 11 (Легковесная утилита флоппи дисков для Windows 95 до Windows 11)

## It has absolutely nothing to do with WinImage or its developer

### Important
The program itself runs on Windows versions 95 through 11

## Features
- **Standalone:** Single executable (~20 KB), zero dependencies.
- **Native:** No .NET, no modern Visual C++ runtimes required.
- **Supported Formats:**
  - 3.5": 1.44 MB, 720 KB, 2.88 MB
  - 5.25": 1.2 MB, 360 KB
- **Operations:** Create new images, view contents, inject files, extract single files, batch extract all files to a folder.
- **100% Free:** No nag screens, no shareware limits.
